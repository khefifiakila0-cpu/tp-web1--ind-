## Présentation du projet
Ce dépôt contient mon **Portfolio Numérique** réalisé tout au long du semestre dans le cadre du module *Digital Skills* et des unités d'enseignement associées (*Développement*, *Systèmes d'exploitation et fondements*, *Développement web côté client*). Il rassemble mes productions écrites, visuelles, multimédias et mes programmes commentés.

## Structure et modules couverts
- **Accueil (`index.html`) :** Présentation personnelle et accès direct aux modules.
- **Digital Skills (`digital-skills/`) :**
  - `cybersecurite.html` : Menaces numériques, bonnes pratiques, checklist interactive et espace infographie.
  - `prompt-engineering.html` : Méthodologie de prompt, 3 cas pratiques comparatifs et bibliothèque de 5 prompts pour les études.
  - `creation-contenu.html` : Hub multimédia autour d'un thème unique (avatar parlant, montage vidéo, résumé, podcast, carte mentale, PowerPoint interactif).
- **Développement (`developpement/`) :**
  - `python.html` : 3 mini-projets Python documentés (problème, code, explication, difficultés/solutions).
  - `langage-c.html` : 3 programmes en langage C + tableau comparatif Python / C.
  - `algorithmique.html` : 3 algorithmes en pseudo-code avec trace pas à pas, traduction Python/C et démonstration interactive JS.
- **Systèmes d'exploitation et fondements (`systemes/`) :**
  - `systemes-exploitation.html` : Architecture fonctionnelle d'un OS, comparatif Windows / Linux / macOS et tutoriel de commandes.
  - `architecture-electronique.html` : Architecture matérielle d'un ordinateur, conversions binaire/hexadécimal et portes logiques.
