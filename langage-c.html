Unité Développement — Langage C

Trois programmes en langage C compilés avec gcc illustrant les types, conditions, boucles, tableaux et pointeurs, suivis d'un comparatif avec Python.

Programme 1 : Calcul de factorielle (boucles et conditions)

#include <stdio.h>

int main(void) {
    int n;
    unsigned long long fact = 1;

    printf("Entrez un entier positif : ");
    if (scanf("%d", &n) != 1 || n < 0) {
        printf("Entree invalide.\n");
        return 1;
    }

    for (int i = 1; i <= n; i++) {
        fact *= i;
    }

    printf("Factorielle de %d = %llu\n", n, fact);
    return 0;
}

Programme 2 : Recherche du minimum et maximum dans un tableau

#include <stdio.h>

int main(void) {
    int tab[5] = {18, 4, 27, 9, 15};
    int min = tab[0], max = tab[0];

    for (int i = 1; i < 5; i++) {
        if (tab[i] < min) min = tab[i];
        if (tab[i] > max) max = tab[i];
    }

    printf("Minimum : %d | Maximum : %d\n", min, max);
    return 0;
}

Programme 3 : Échange de deux variables par pointeurs

#include <stdio.h>

void echanger(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 10, y = 25;
    printf("Avant : x = %d, y = %d\n", x, y);
    echanger(&x, &y);
    printf("Apres : x = %d, y = %d\n", x, y);
    return 0;
}

Tableau comparatif : Python vs Langage C

CritèrePythonLangage C
SyntaxeÉpurée, basée sur l'indentation, proche de l'anglais.Plus stricte, utilisation d'accolades {} et de points-virgules ;.
TypageDynamique (le type est déduit automatiquement à l'exécution).Statique et explicite (chaque variable doit être déclarée avec son type).
Gestion de la mémoireAutomatique grâce au ramasse-miettes (Garbage Collector).Manuelle via les pointeurs et fonctions malloc / free.
Rapidité d'exécutionPlus lent car langage interprété (bytecode).Très rapide car compilé directement en code machine natif.
Usages principauxData science, IA, scripts d'automatisation, développement web backend.Systèmes d'exploitation, systèmes embarqués, pilotes, logiciels critiques.
