Mini-projet 1 : Calculatrice interactive en ligne de commande

Problème : Permettre à un utilisateur d'effectuer des opérations arithmétiques de base (+, -, *, /) en boucle tout en gérant la division par zéro et les saisies invalides.

def calculatrice():
    while True:
        choix = input("Opération (+, -, *, /) ou 'q' pour quitter : ").strip()
        if choix.lower() == 'q':
            print("Fin du programme.")
            break
        if choix not in ('+', '-', '*', '/'):
            print("Opérateur invalide.")
            continue
        try:
            a = float(input("Premier nombre : "))
            b = float(input("Deuxième nombre : "))
            if choix == '+':
                print(f"Résultat : {a + b}")
            elif choix == '-':
                print(f"Résultat : {a - b}")
            elif choix == '*':
                print(f"Résultat : {a * b}")
            elif choix == '/':
                if b == 0:
                    print("Erreur : division par zéro impossible.")
                else:
                    print(f"Résultat : {a / b:.2f}")
        except ValueError:
            print("Erreur : veuillez saisir des nombres valides.")

if __name__ == "__main__":
    calculatrice()

Fonctionnement : Une boucle while demande l'opérateur puis convertit les entrées en flottants dans un bloc try/except pour éviter un arrêt brutal en cas de saisie textuelle.

Difficulté & solution : Le programme plantait si l'utilisateur entrait des lettres au lieu d'un nombre ; résolu avec try/except ValueError.

Mini-projet 2 : Jeu du nombre mystère

Problème : L'ordinateur choisit un entier aléatoire entre 1 et 100 et guide le joueur (« Trop petit » / « Trop grand ») jusqu'à la victoire en comptant les essais.

import random

def jeu_devinette():
    secret = random.randint(1, 100)
    essais = 0
    print("Devinez le nombre entre 1 et 100 !")
    while True:
        try:
            proposition = int(input("Votre proposition : "))
            essais += 1
            if proposition < secret:
                print("Trop petit !")
            elif proposition > secret:
                print("Trop grand !")
            else:
                print(f"Bravo ! Trouvé en {essais} essai(s).")
                break
        except ValueError:
            print("Entrez un entier valide.")

if __name__ == "__main__":
    jeu_devinette()

Fonctionnement : Utilise random.randint(1, 100) et incrémente un compteur essais à chaque tentative valide jusqu'à l'égalité.

Difficulté & solution : J'avais initialement placé random.randint à l'intérieur de la boucle, ce qui changeait le nombre à chaque tour ; corrigé en le sortant avant le while.

Mini-projet 3 : Gestionnaire de notes d'étudiant

Problème : Saisir les notes d'un module, calculer la moyenne générale, identifier la note minimale/maximale et afficher la mention.

def gestionnaire_notes():
    notes = []
    n = int(input("Combien de notes souhaitez-vous saisir ? "))
    for i in range(n):
        note = float(input(f"Note {i + 1} (/20) : "))
        while note < 0 or note > 20:
            note = float(input("Note invalide (0 à 20). Recommencez : "))
        notes.append(note)

    moyenne = sum(notes) / len(notes)
    print(f"Notes : {notes}")
    print(f"Moyenne : {moyenne:.2f}/20 | Min : {min(notes)} | Max : {max(notes)}")
    if moyenne >= 10:
        print("Statut : Module validé")
    else:
        print("Statut : Ajourné")

if __name__ == "__main__":
    gestionnaire_notes()

Fonctionnement : Stocke les notes validées (entre 0 et 20) dans une liste Python puis exploite les fonctions natives sum(), len(), min() et max().

Difficulté & solution : Validation des bornes [0, 20] ajoutée avec une boucle interne pour éviter de fausser la moyenne.
