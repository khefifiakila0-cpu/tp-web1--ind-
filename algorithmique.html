Trois algorithmes fondamentaux présentés en pseudo-code avec exemple pas à pas et traduction en code.

Algorithme 1 : Recherche du maximum dans un tableau

Idée générale : Supposer que le premier élément est le plus grand, puis parcourir le reste du tableau en mettant à jour le maximum dès qu'une valeur supérieure est rencontrée.

Algorithme RechercheMax
Variables
    T : Tableau[0..N-1] d'entiers
    i, max : Entier
Début
    max <- T[0]
    Pour i de 1 à N - 1 Faire
        Si T[i] > max Alors
            max <- T[i]
        FinSi
    FinPour
    Afficher("Maximum = ", max)
Fin

Exemple pas à pas sur [12, 45, 7, 30] : Initialisation max = 12 → i=1 (45 > 12 → max = 45) → i=2 (7 < 45) → i=3 (30 < 45) → Résultat : 45.

Traduction Python : max_val = T[0]; [max_val := x for x in T[1:] if x > max_val] (ou boucle classique for x in T:).

Algorithme 2 : Recherche séquentielle d'un élément

Idée générale : Parcourir les cases du tableau une par une jusqu'à trouver la valeur recherchée ou atteindre la fin du tableau.

Algorithme RechercheSequentielle
Variables
    T : Tableau[0..N-1] d'entiers
    i, cible, pos : Entier
Début
    pos <- -1
    i <- 0
    TantQue (i < N) ET (pos = -1) Faire
        Si T[i] = cible Alors
            pos <- i
        Sinon
            i <- i + 1
        FinSi
    FinTantQue
    Afficher("Position = ", pos)
Fin

Exemple pas à pas sur [8, 19, 3, 25] avec cible = 3 : i=0 (8 ≠ 3) → i=1 (19 ≠ 3) → i=2 (3 = 3 → pos = 2, arrêt de la boucle).

Algorithme 3 : Tri à bulles (Bubble Sort)

Idée générale : Comparer les éléments adjacents deux à deux et les échanger s'ils sont mal ordonnés, faisant remonter les plus grandes valeurs à la fin à chaque passage.

Algorithme TriBulles
Variables
    T : Tableau[0..N-1] d'entiers
    i, j, temp : Entier
Début
    Pour i de 0 à N - 2 Faire
        Pour j de 0 à N - 2 - i Faire
            Si T[j] > T[j + 1] Alors
                temp <- T[j]
                T[j] <- T[j + 1]
                T[j + 1] <- temp
            FinSi
        FinPour
    FinPour
Fin
